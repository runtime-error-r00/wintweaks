Use the Tweaks tab to apply a short list of tested Windows changes. Every tweak shows what it does and how risky it is, and you are offered a System Restore point once, at the moment you apply your selection.

![Image of Tweaks Tab](../../../assets/screenshots/tweaks-tab-new.png)

### Reading a tweak

Each row has three parts:

* **Checkbox**: selects the tweak. Ticking a box changes nothing on its own.
* **Risk dot**: green is low risk, orange is medium (read the side effects), red is high (only if you know you need it).
* **Info icon**: hover it to read, in plain language, what the tweak changes and what side effects to expect.

The tweaks are grouped into **Privacy**, **System**, **Performance**, **Interface** and **Advanced - Caution**.

### Recommended Selections
Use the quick-selection buttons at the top of the Tweaks tab to speed up setup:

* **Standard**: The recommended baseline for most PCs: privacy, system and cleanup tweaks.
* **Minimal**: A smaller, lower-impact set.
* **Advanced**: Standard plus Windows AI removal, best-performance visual effects and the classic right-click menu.
* **Clear**: Clears all currently selected tweaks.
* **Select Installed Tweaks**: Best-effort detection for tweaks already applied to your system.

:::note
To see what each preset includes, view [preset.json](https://github.com/runtime-error-r00/wintweaks/blob/main/config/preset.json).
:::

### Run Tweaks
1. Select the tweaks you want, or start from a preset.
2. Click **Run Tweaks** at the bottom of the screen.
3. Answer the restore point question:
   * **Yes** creates a System Restore point, then applies the tweaks.
   * **No** applies the tweaks without one.
   * **Cancel** goes back without changing anything.

If the restore point cannot be created (for example, System Protection is blocked by policy), you are asked whether to continue without it. Runs started with `-Preset` or `-Config`, which have no window, always try to create one first and continue with a warning in the log if they cannot.

When a listed service does not exist, WinTweaks logs a warning and skips it. The remaining services and tweaks still run.

:::caution
Some tweaks take effect immediately, while others need File Explorer to restart, a sign-out, or a full reboot. The info icon says which.
:::

### Undo Tweaks
1. Select the tweaks you want to revert.
2. Click **Undo Selected Tweaks**.

One-off actions, such as Disk Cleanup, have nothing to undo. Windows AI removal restores its settings, but removed apps have to be reinstalled from the Microsoft Store.

### Performance Power Plan

The **Performance Power Plan - Enable** tweak creates and activates a plan named *WinTweaks Performance*: the processor stays at 100%, the hard disk never turns off, sleep and hibernation timeouts are off and the wireless adapter runs at maximum performance. It reduces battery life on laptops. Undo switches back to Balanced and deletes the plan.

### Advanced Page

The **Advanced** page in the sidebar (Alt+A) holds gaming and latency optimizations for experienced users. They trade power use, heat and in some cases security for lower latency. The page shows four buttons:

* **General System Optimizations**: low-latency system timers, CPU scheduling for games, faster shutdown and menus, power latency tolerance, web search, diagnostics, notifications, background apps and similar system settings.
* **Keyboard and Mouse Optimizations**: accessibility shortcut keys, mouse acceleration, keyboard repeat, input process priority and USB power saving, plus the mouse and keyboard data queue size.
* **GPU Optimizations**: hardware-accelerated GPU scheduling plus NVIDIA, AMD and Intel driver settings. Only the graphics cards found on this PC are changed; the page says which ones it found.
* **CPU Optimizations**: core parking and throttling, sleep states, CPU quotas and Intel-only boot settings, applied to the power plan that is active at that moment.

Each button opens a page that lists what the group changes (hover a line for details) with three buttons:

* **Apply** applies the whole group straight away, after the usual restore point question.
* **Revert** undoes the whole group.
* **Back to menu** returns to the four buttons.

Two settings are not part of Apply. The data queue size is a drop-down on the Keyboard and Mouse page and is applied as soon as you choose a value. Core Isolation (Memory Integrity) has its own **Disable** and **Enable** buttons on the General page.

Driver, USB and power plan settings record the values your PC had before the first run under `HKLM\SOFTWARE\WinTweaks\Backup`, and Revert puts exactly those values back. Most Advanced optimizations take effect after a restart.

### AppX Packages

Open **AppX Removal** from the Tweaks tab to manage the listed Windows apps. Select one or more packages, then choose **Install Selected** or **Remove Selected**.

When installing a selected package, WinTweaks first registers an existing local `AppxManifest.xml`. If no usable local manifest remains, it installs the package from the Microsoft Store through WinGet when a Store product ID is available.

During AppX installation or removal, the window-level progress bar shows the current package, completed package count, and overall progress. The Windows taskbar also reflects progress and the final success or failure state.

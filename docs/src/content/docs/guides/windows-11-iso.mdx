The **Windows 11 ISO** page, last in the sidebar, offers a Windows 11 installation image already modded by WinTweaks:

* **No Microsoft bloat**: the useless apps and extras Microsoft preinstalls are already removed.
* **Local account**: Windows is set up with a local account instead of asking you to sign in with a Microsoft account.
* **Faster installation**: installation finishes faster than with the standard Windows 11 ISO.

Click **Download** to open the download page on MEGA in your default browser, and download the ISO from there. WinTweaks itself does not download or change anything. MEGA may limit how much a free visitor can download in a few hours; if the download pauses, wait or sign in to MEGA.

Write the ISO to a USB stick or mount it, then install Windows as usual.
